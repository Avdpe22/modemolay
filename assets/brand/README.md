# Missouri DeMolay lockups

The four SVGs in `../` are generated by `build-logo.py`. **Edit the script, not the
SVGs** — regenerating overwrites them.

```bash
pip install fonttools
curl -sLO https://github.com/google/fonts/raw/main/ofl/barlow/Barlow-Bold.ttf
python3 build-logo.py Barlow-Bold.ttf ..
```

## What these are

They reproduce the structure of the **DeMolay International** mark — gold stars
flanking a red shield, the stylised "DeMOLAY" wordmark with a navy fill, white gap and
gold outline, and the jurisdiction name in red beneath — with **MISSOURI** in place of
INTERNATIONAL. That is the standard jurisdiction pattern.

> **Not yet approved.** These were derived from the DI mark, not supplied by DI or the
> jurisdiction. They need sign-off from the Executive Officer and DeMolay International
> before launch. See `BLOCKED-ITEMS.md` #6. If DI supplies official Missouri artwork,
> drop it in and delete this folder.

Letterforms are converted to SVG **paths**, so the marks never shift if a webfont fails
to load. Type is Barlow Bold (SIL OFL 1.1) — the site's display face. The wordmark paths
are defined once in `<defs>` and referenced per outline layer with `<use>`, which is why
the files are ~8 KB rather than ~43 KB.

## Which file goes where

| File | Ratio | Use |
|---|---|---|
| `logo-horizontal.svg` | 3.9:1 | Site header (light background) |
| `logo-horizontal-white.svg` | 3.9:1 | Header on a dark background — not currently used |
| `logo-stacked.svg` | 3.1:1 | Anywhere shown large on a light background — print, social, slides |
| `logo-stacked-white.svg` | 3.1:1 | Site footer (`#081525`) |

Two ratios exist because one cannot serve both sizes. The stacked lockup carries the
full star row and only holds up above roughly 90px tall; below that the stars merge and
MISSOURI stops being legible. The horizontal lockup drops the star row, keeps the
shield, and sets MISSOURI proportionally larger so it still reads at the 46px the nav
bar allows.

## Colours

Sampled from the supplied DI artwork; confirm against DI's Brand Center before launch.

| | Hex |
|---|---|
| Navy | `#1D3A63` |
| Gold | `#FFC629` |
| Red | `#EE2737` |

These are **not** the site's palette (`--ink #0B1D33`, `--gold #C9A227`, `--red #B22234`)
— the mark keeps DI's brighter brand colours and sits against the site's own. If the EO
wants them reconciled, change `NAVY`/`GOLD`/`RED` at the top of the script.
